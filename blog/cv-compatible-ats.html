CV compatible ATS : passer les filtres de recrutement

Mis à jour en 2026 · Lecture ~7 min

Vous envoyez des candidatures, votre profil correspond, et pourtant : silence. Souvent, votre CV n'a jamais été lu par un humain. Il a été écarté par un ATS, le logiciel de tri utilisé par de nombreux recruteurs. Bonne nouvelle : rendre son CV compatible ATS ne demande ni talent graphique ni astuce secrète — juste quelques règles simples, expliquées ici.

Qu'est-ce qu'un ATS ?

Un ATS (Applicant Tracking System, ou système de suivi des candidatures) est le logiciel avec lequel les entreprises reçoivent, stockent et trient les candidatures. Quand vous postulez via un formulaire en ligne — sur JobUp, Jobs.ch ou le site carrière d'une entreprise — votre CV atterrit très probablement dans un ATS.

Concrètement, le logiciel :

  • Extrait le texte de votre CV et le range dans des champs (expérience, formation, compétences, coordonnées) ;
  • Compare ce contenu aux critères de l'annonce, souvent via des mots-clés ;
  • Classe ou filtre les candidatures pour que le recruteur examine en priorité les profils jugés les plus proches du poste.

Le problème : l'ATS ne lit pas comme un humain. Il ne « voit » pas votre mise en page — il extrait du texte brut. Si votre CV est mal structuré ou mal formaté, le logiciel peut mélanger vos rubriques, perdre des informations ou ne rien extraire du tout.

Pourquoi des candidats qualifiés sont écartés automatiquement

Un CV peut être écarté par un ATS pour des raisons qui n'ont rien à voir avec vos compétences :

  • Le vocabulaire ne correspond pas : vous écrivez « gestion de projet » alors que l'annonce dit « chef de projet », vous utilisez un intitulé de poste maison que le logiciel ne reconnaît pas, ou vous omettez une compétence que vous maîtrisez parce qu'elle vous semble évidente.
  • La mise en page casse l'extraction : colonnes multiples, tableaux, zones de texte, en-têtes et pieds de page — autant d'éléments que certains ATS lisent mal ou dans le désordre.
  • L'information est dans une image : un bandeau graphique avec vos coordonnées, une jauge de compétences, un logo — pour l'ATS, c'est invisible.
  • Le fichier lui-même pose problème : un PDF scanné (une image de votre CV) ne contient aucun texte extractible.

Résultat : un candidat parfaitement qualifié peut se retrouver en bas du classement, tandis qu'un profil moins pertinent mais mieux formaté passe devant. C'est frustrant — mais c'est aussi une opportunité : peu de candidats optimisent leur CV pour les ATS.

Les mots-clés : parlez la langue de l'annonce

Le levier le plus puissant est aussi le plus simple : reprendre les termes exacts de l'annonce — honnêtement, uniquement pour ce que vous maîtrisez réellement.

Comment faire concrètement

  • Relisez l'annonce en surlignant les compétences, outils, certifications, langues et intitulés mentionnés. Ce sont vos mots-clés cibles.
  • Utilisez l'intitulé du poste de l'annonce dans le titre de votre CV, s'il correspond à votre profil.
  • Écrivez les termes tels quels : si l'annonce dit « comptabilité fournisseurs », n'écrivez pas seulement « gestion des créanciers ». En cas de doute, utilisez les deux formulations.
  • Épelez les sigles ET leur version longue au moins une fois (par exemple : « ERP », mais aussi le nom du logiciel précis demandé).
  • Placez les mots-clés dans le contexte de vos expériences, pas seulement dans une liste : un mot-clé relié à une réalisation concrète pèse plus, pour le logiciel comme pour le recruteur qui lira ensuite.

Cela implique d'adapter votre CV à chaque offre. C'est l'étape que la plupart des candidats sautent — et c'est pourtant celle qui rapporte le plus. L'outil gratuit cv.radarjob.ch vous aide à adapter votre CV à une offre précise en quelques minutes.

La mise en page : simple, sobre, une colonne

Un CV compatible ATS n'est pas un CV laid — c'est un CV épuré. Les règles :

  • Une seule colonne, de haut en bas. Les mises en page à deux colonnes sont la première cause de lecture désordonnée.
  • Pas de tableaux, pas de zones de texte pour structurer le contenu.
  • Aucune information essentielle dans une image : coordonnées, compétences et titres doivent être du texte réel. Bannissez les jauges et graphiques de compétences — indiquez plutôt un niveau en toutes lettres.
  • Coordonnées dans le corps du document, pas uniquement dans l'en-tête ou le pied de page, que certains logiciels ignorent.
  • Titres de rubriques standards : « Expérience professionnelle », « Formation », « Compétences », « Langues ». Les intitulés créatifs (« Mon parcours ») perturbent le classement automatique.
  • Police classique et lisible (Arial, Calibri, Helvetica ou équivalent), sans puces exotiques ni caractères spéciaux décoratifs.
  • Dates cohérentes : un format uniforme (par exemple « 01.2023 – 06.2025 ») pour toutes les expériences.

Bonus : cette sobriété correspond exactement à ce que les recruteurs suisses attendent d'un dossier, comme expliqué dans notre guide complet du CV suisse.

Le format de fichier : PDF texte, jamais scanné

  • PDF exporté depuis votre traitement de texte (Word, Google Docs, LibreOffice…) : c'est le format le plus sûr. Le texte reste sélectionnable et extractible.
  • Jamais de PDF scanné ou de photo de votre CV : le logiciel n'y voit qu'une image vide de texte.
  • Test rapide : ouvrez votre PDF et essayez de sélectionner le texte à la souris, puis copiez-collez-le dans un document vierge. Si le texte se copie proprement et dans le bon ordre, c'est bon signe. S'il sort dans le désordre ou pas du tout, l'ATS aura le même problème.
  • Respectez le format demandé : si le formulaire exige un Word (.docx), fournissez un Word.
  • Nommez le fichier proprement : Prenom_Nom_CV.pdf plutôt que « cv_final_v3(2).pdf ».

En résumé

Un ATS n'écarte pas les mauvais candidats — il écarte les CV qu'il n'arrive pas à lire ou à relier à l'annonce. Pour passer les filtres : reprenez honnêtement les mots-clés de l'offre, adoptez une mise en page à une colonne sans tableaux ni informations dans des images, exportez un PDF texte (jamais scanné), et testez votre CV gratuitement avant d'envoyer. Adapté à chaque offre, votre CV franchira le filtre logiciel — et convaincra l'humain derrière.
